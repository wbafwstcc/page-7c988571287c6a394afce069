线路覆盖香港、新加坡、日本、台湾与美国等常用区域；旗舰版提供 IPLC 专线游戏优化，团队版提供更高带宽与定制路由。我们强调可预期的月度流量与设备数，而不是含糊的“不限速口号”。

使用场景

流媒体与内容访问

需要观看海外影视、音乐或直播时，选择支持原生解锁的套餐，优先使用对应地区节点，减少验证失败。旗舰版与团队版更适合全节点解锁需求。

跨境办公与学习

视频会议、云盘协作、论文数据库与代码仓库访问时，稳定比极限带宽更重要。建议固定一条低抖动线路，并在客户端开启规则分流，让国内站点直连。

游戏加速与实时语音

对延迟敏感的手游或端游，可使用旗舰版 IPLC 优化节点。先测延迟再开游戏，避免在高峰期频繁切换导致掉线。

多设备同时在线

手机、电脑与平板同时使用时，请核对套餐设备上限。基础版适合轻度三设备，团队版面向工作室或家庭共享。

配置流程

长颈鹿把上手路径压缩为五步。按顺序完成即可，无需改系统代理以外的高级项。若中途失败，回到上一步核对订阅类型与客户端版本。

第一步：在官网选定套餐

根据设备数与流量选择基础版、旗舰版或团队版。年付适合长期使用。下单完成后进入用户中心，确认套餐已生效。

第二步：复制机场订阅链接

在控制台找到 Clash / 通用订阅地址。不要把链接发到公开群组。如需分流，可同时复制规则模板说明，稍后在客户端粘贴。

第三步：下载对应客户端

Windows 可用 Clash Verge 或 v2rayN；macOS 可用 ClashX Meta 或 Surge；Android 可用 Clash Meta for Android；iOS 常用 Shadowrocket 或 Quantumult X。请从应用商店或项目发布页获取，本页仅提供导入说明。

第四步：导入订阅并更新节点

打开客户端的订阅栏，粘贴长颈鹿订阅 URL，执行更新。确认节点列表出现香港、日本、美国等条目。开启系统代理或 TUN 模式，按规则分流。

第五步：选择节点并验证

先选延迟较低的节点访问常用网站，再测试目标流媒体或游戏。若解锁失败，换同区域备用节点。保持客户端自动更新订阅，以免节点变更后失效。

常见问题

长颈鹿机场是什么？和长颈鹿VPN有何关系？

长颈鹿机场指可订阅的节点与流量套餐服务，长颈鹿VPN是同一品牌在客户端侧的加速用法。两者共用官方订阅，区别只是叫法：买的是机场套餐，用的是 VPN/代理客户端。

如何完成长颈鹿客户端下载后的第一次连接？

安装客户端 → 粘贴官网用户中心的订阅链接 → 更新节点 → 选择低延迟线路 → 打开系统代理。若浏览器仍走直连，检查是否漏开 TUN 或系统代理开关，并确认没有其他代理软件抢占端口。

订阅链接泄露了怎么办？

立刻在用户中心重置订阅。旧链接将失效，需在所有设备重新导入。不要把订阅发到论坛或截图。团队版如需多人使用，用套餐设备额度管理，而不是把同一链接随意扩散。

基础版、旗舰版和团队版该怎么选？

轻度浏览与三设备选基础版；需要流媒体全解锁、游戏 IPLC 与优先支持选旗舰版；工作室、家庭多设备或需要定制路由选团队版。流量以实际 4K 与会议时长估算，宁可选对档位也不要频繁超限。

节点连不上或流媒体不能播放如何排查？

先更新订阅，换同地区节点，关闭再打开代理。确认系统时间准确。流媒体失败时改用旗舰版解锁节点，并避免全局模式把国内视频也送出国。仍失败可提交工单并附客户端日志时间点。

长颈鹿是否记录上网日志？官方如何联系？

服务按最小化记录原则运行，仅保留开通与工单所必需的账号信息。联系方式以用户中心工单为准，旗舰版与团队版享有更高响应优先级。请认准长颈鹿官网域名，谨防仿冒下载页。
